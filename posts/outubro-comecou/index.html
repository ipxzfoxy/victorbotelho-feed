Outubro de 2026 chegou... Bora ver o que tenho planejado pra esse mês?

O mês já começou com Disfox ganhando 3 releases. E dá pra dizer com certeza que esse mês vai ser bem mais focado nele e em outro projeto que eu já havia mencionado do que no ProtoIndigo.

O Disfox vai passar por grandes mudanças. Há meses venho planejando novas releases e funcionalidades para o framework, porém, nesses últimos dias, comecei a repensar bastante a API atual.

A API do Disfox já reduz bastante código em comparação ao discord.js, mas estive explorando novos padrões que podem reduzir ainda mais trabalho desnecessário e deixar o desenvolvimento de bots mais simples e direto.

Planejo focar bastante no Disfox durante outubro para trazer essa nova API ao framework e prepará-lo para receber três novas grandes ferramentas.

Disfox Visual, Disfox Carmin e Disfox CLI estão oficialmente em cena!

Comecei a projetar essas três ferramentas nos últimos dias. A ideia é trazer novas abstrações e automatizações para o desenvolvimento de bots no Discord, incluindo sistemas de tickets, manipulação de interfaces dentro da plataforma e novas ferramentas para criação e gerenciamento de projetos Disfox.

Mas existe outro projeto novo que também precisa ser prioridade neste mês. Então não posso garantir que tudo isso seja lançado ainda em outubro.

Mesmo assim, uma coisa já está clara: outubro vai ser um mês importante para o Disfox.
